LiveKit · Access API

LiveKit Token Server

Create access tokens for real-time audio, video, and data rooms. Your client uses the returned token and server URL to connect to LiveKit.

Check server health

Open GET /health to check the API status.

Create a room token

Send POST /token with Content-Type: application/json and the following body:

{
  "roomName": "demo",
  "participantName": "alice"
}

The response includes serverUrl, roomName, participantName, and token. Tokens last one hour and allow joining the room, publishing, subscribing, and sending data.
